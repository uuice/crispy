Crispy AI Agent — 查一篇文章

示例：「帮我找一篇关于 Docker 部署的文章」— 从 Admin UI 到 DeepSeek 再到 Payload 查库

Agent Crispy 产品层 DeepSeek 默认上游 LLM 协议 OpenAI Chat Completions + Tools API POST /api/ai/agent

角色分工

Crispy Agent — 鉴权、工具执行、Payload 读写、会话持久化
DeepSeek — 理解意图、选择工具、阅读 JSON 结果、中文回复
Postgres / Payload — 真实数据；语义搜索另需 pgvector + Embedding API

时序图

sequenceDiagram participant U as Admin UI participant API as /api/ai/agent participant Agent as runAiAgentStream participant LLM as DeepSeek participant Tool as executeAgentTool participant DB as Payload / Postgres U->>API: POST 用户消息 SSE API->>API: auth editor+ 存会话 API->>Agent: sanitizedMessages Agent->>LLM: system + tools 定义 LLM-->>Agent: tool_call semantic_search Agent->>Tool: executeAgentTool Tool->>DB: embedding 或 payload.find Tool-->>Agent: JSON 结果 Agent->>LLM: role tool 回传 LLM-->>Agent: 流式 text 总结 Agent-->>API: SSE events API-->>U: 显示回答

七步流程

  1. 你在 Admin 发消息 AI 助手 Widget → consumeAgentStream → POST /api/ai/agent，body 含 messages 与可选 sessionId。
  2. Crispy 鉴权与存会话 payload.auth 校验 cookie；canUseAiAgent 要求 editor+；写入 ai-chat-sessions；createLocalReq({ user }) 后续工具用你的权限。
  3. 组装对话并发给 DeepSeek buildAgentSystemPrompt() + 历史消息；resolveAiSettings() 读 ai-settings + .env；请求 /v1/chat/completions 并附带 AGENT_TOOLS。
  4. DeepSeek 选择查法 模糊描述 → semantic_search；精确 slug/条件 → find_documents；要看全文 → get_document。
  5. Crispy 执行工具查库 overrideAccess: false 尊重你的 Collection read 权限；列表不含大正文。
  6. 多轮 tool loop（最多 8 轮） 工具结果以 role: tool 塞回对话；模型继续调工具或输出最终回答。
  7. SSE 流式展示 tool_start / tool_result / text / done；会话持久化可续聊。

两种查文章路径

路径 A — semantic_search（自然语言）

「找一篇讲 Docker 部署的」

{
  "name": "semantic_search",
  "arguments": {
    "query": "Docker 部署",
    "collections": ["posts"],
    "limit": 8
  }
}
  • embedText(query) → Embedding API
  • Postgres pgvector 相似度搜索
  • 需 PGVECTOR_ENABLED + LLM_EMBEDDING_API_KEY

路径 B — find_documents（精确条件）

「查 slug 是 docker-deploy 的文章」

{
  "name": "find_documents",
  "arguments": {
    "collection": "posts",
    "where": {
      "slug": { "equals": "docker-deploy" }
    },
    "limit": 10
  }
}
  • payload.find + Payload where
  • 不依赖 pgvector
  • 列表字段精简，无全文

读全文 — get_document

{
  "name": "get_document",
  "arguments": {
    "collection": "posts",
    "id": 42,
    "depth": 1
  }
}

→ payload.findByID，返回 Lexical 正文、分类、发布状态等。
